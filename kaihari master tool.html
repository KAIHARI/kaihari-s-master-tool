What is a YDKX file?

YDKX is an enhanced version of the standard YDK format that includes:

  • Card Pool Data: Stores which cards are available in your collection
  • Deck Configurations: Saves siding patterns, card scales, and other settings
  • Extended Metadata: Preserves deck names, timestamps, and custom configurations
  • Better Compatibility: Works seamlessly with this tool's advanced features

💡 Use YDKX for the best experience with this deck builder!

💡 Use the Import YDK button in the header to import .ydk/.ydkx files
